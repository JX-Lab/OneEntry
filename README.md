# 一笔 OneEntry

一笔是一款本地 Android 账本，用于记录个人或同一设备上多名成员的收入、支出、账户余额、预算和资金归属。

它不要求注册账号，账本默认只保存在设备中。一个成员时可以作为普通个人账本使用；添加成员后，可以继续区分收支归属、扣款或入账荷包、实际账户、发起者和记录者。

## 主要功能

- 记录收入、支出和账户转账，支持算式金额、组合付款、周期账目和账目修改历史。
- 管理现金、银行卡、支付账户、信用账户和贷款账户，查看账户净额与负债。
- 通过成员荷包和公共资金记录资金归属，并自动计算成员之间的待结算往来。
- 单人支出默认使用该成员荷包，多人或全体支出默认使用公共资金，也可逐笔调整。
- 设置月度总预算、分类预算和可选的成员预算，查看月、周、年统计。
- 搜索和批量整理账目、账户、成员及标签。
- 导出 JSON、ZIP、XLSX 备份，并支持从旧版一笔及其他账本导入。
- 提供本地快照、每日提醒、主题、文字大小和多种无障碍显示选项。

## 先理解四个概念

| 概念 | 表示什么 | 示例 |
| --- | --- | --- |
| 账户 | 钱实际存放或负债记录的位置 | 现金、支付宝、银行卡、信用卡、房贷 |
| 成员荷包 | 某位成员可支配的资金总额，不绑定某张银行卡 | 「我」的 ¥200 可以从任意实际账户支付 |
| 公共资金 | 没有分配给某位成员、全体都能使用的资金 | 公共生活费、共同收入 |
| 账目角色 | 一笔账中互相独立的信息 | 收支归属、扣款／入账荷包、实际账户、发起者和记录者 |

账户与成员荷包是两套信息：账户回答「钱在哪里」，荷包回答「钱归谁使用」。一笔支出可以由多个账户组合扣款，也可以由多个成员按 AA 或自定义金额承担。

## 记一笔

- 记录支出、收入和账户之间的转账。
- 转账只改变两个实际账户的余额，不计入收入或支出，也不绑定归属、发起者或记录者。
- 金额支持 `+ - × ÷` 和括号，保存时自动计算。
- 「支出归属／收入归属」决定计入哪些成员的统计，支持多选和自定义金额。
- 「扣款荷包／入账荷包」决定减少或增加公共资金、哪个成员荷包。
- 「付款账户／收款账户」表示钱实际从哪里扣除或存入。
- 发起者和记录者是可选信息，不影响账户、荷包和收支统计。
- 设置中可以统一选择多人金额按 AA 均摊，或每笔自由填写金额。
- 「记录」可以留空、选择一人或多人，用来表示是谁记下了这笔账。
- 一个实际账户余额不足时，可以按账户顺序自动补足，或手动组合多个账户的金额。
- 支出可以标记为预算外：仍计入总支出，但不占用当月预算。
- 账目详情会保留修改历史，并支持「再记一笔」。

## 成员荷包与往来

- 成员页统一管理公共资金、成员荷包和成员之间的待结算往来。
- 分配荷包时只需填写成员金额，剩余资金自动留在公共资金。
- 可以分别设置一人、部分成员和全体成员支出时优先使用成员荷包或公共资金。
- 可以为单个成员设置独立规则，覆盖参与人数对应的默认规则。
- 荷包不足时，可以选择公共资金或其他成员荷包继续支付。
- 使用公共资金不会产生借款；使用其他成员荷包会自动生成待结算往来。
- 往来可以部分结算，也可以一次结清。
- 按成员查看月度收入、支出、参与账目和相关明细。
- 归档成员不再计入当前成员统计和多人记账，其剩余荷包余额会转回公共资金。

## 账户与负债

| 账户类型 | 用途 |
| --- | --- |
| 资产账户 | 存放实际资金，用于日常收支，余额最低为 0 |
| 信用／透支账户 | 可以直接付款，并在信用额度内出现负数，例如信用卡、花呗 |
| 贷款／负债账户 | 只追踪尚未偿还的本金，不作为日常付款账户，例如房贷 |

- 账户页显示当前未归档账户的净额、账户数量与负债。
- 余额调整会同步公共资金；若减少额超过公共资金，需要先在「荷包与往来」重新分配。
- 有历史账目的账户建议归档，历史记录会继续保留；归档余额不计入当前净额、负债和荷包总额。
- 只有余额为 0 且没有历史账目的空账户可以永久删除，避免账户和荷包数据失衡。

## 预算与统计

- 按月设置全体总预算和分类预算。
- 成员预算是可选项，不要求把总预算分完。
- 预算外花销单独统计。
- 按年、月、周查看收入与支出趋势。
- 收入使用蓝色，支出使用红色，并同时显示正负号、文字和精确金额。
- 查看分类构成、成员构成和明细下钻。
- 按账户或成员查看每个月的收入、支出合计与相关账目。

## 搜索与批量整理

- 全局搜索分类、账户、成员、金额、日期和备注。
- 按日期、分类、账户、支出／收入归属成员、记录成员和备注筛选。
- 批量修改分类、账户、支出／收入归属、记录和备注。
- 标签可以新建、改名、调整顺序、合并或移除。
- 账户与成员列表支持搜索、排序和归档。

## 提醒与周期账目

- 每日记账提醒支持自定义时间。
- 按天、周、月或年管理房租、订阅等周期账目。
- 到期后发送通知，点击通知进入已填写的记账草稿，由用户确认保存。
- 设置页显示下次提醒和上次成功发送时间。

## 数据、备份与隐私

- 无需账号，账本保存在应用内部的 SQLite 数据库中。
- 应用不会自动把账本上传到一笔的服务器。
- 设置页会显示当前版本；只有主动点击「检查更新」时才会连接 GitHub Releases，不会在后台自动检查，也不会上传账本或设备信息。
- 可以自行把导出的文件保存到网盘或其他设备；这是用户控制的文件备份，不是实时同步。
- 导出 JSON、ZIP 或 XLSX 完整备份。
- 支持从一笔旧备份、同旅、时光序和通用表格导入。
- 每周自动生成本地快照；导入、恢复和清空数据前会创建保护快照。
- 已验证 `main` 旧版 v5 数据库和完整归档可升级、恢复到当前 v9 数据结构。

> 本地快照会随应用卸载一起删除，不能代替保存在其他位置的完整备份。

## 显示与无障碍

- 日间、夜间和跟随系统主题。
- 多种主题色、桌面图标和文字大小。
- 支持增强颜色对比，以及红色觉、绿色觉、蓝黄色觉异常和全色盲模式。
- 支持窄屏和放大字体；高密度条目会自动改为上下排列。
- 输入框失焦或键盘收起时不显示多余描边，聚焦状态仍保持清楚。

## 安装

一笔支持 Android 6.0 及以上系统。

1. 打开 [Releases](https://github.com/TheAnonymous-sys/OneEntry/releases)。
2. 下载适合设备的 APK。
3. 允许浏览器或文件管理器安装来自该来源的应用，然后完成安装。

| APK | 适用设备 |
| --- | --- |
| `arm64-v8a` | 绝大多数现代 Android 手机和平板 |
| `armeabi-v7a` | 较旧的 32 位 ARM 设备 |
| `x86_64` | Android 模拟器或 x86 设备 |

如果不确定，通常选择 `arm64-v8a`。

### 可选权限

| 权限 | 用途 |
| --- | --- |
| 网络 | 用户主动检查更新时读取 GitHub Releases，并在浏览器中打开下载页 |
| 通知 | 每日提醒和周期账目提醒 |
| 闹钟和提醒 | Android 12 及以上系统中尽量准时发送每日提醒 |

## 常见问题

<details>
<summary><strong>账本会自动同步到云端吗？</strong></summary>

不会。一笔目前是本地优先账本，不要求登录，也不会自动上传账本。多人使用时默认是同一设备共用；需要云端保存时，可以自行上传导出的备份文件。

</details>

<details>
<summary><strong>成员荷包需要绑定银行卡吗？</strong></summary>

不需要。成员荷包记录某位成员在全体资金中可以使用的金额，可以从任意实际账户支付。银行卡、现金和支付软件仍由账户单独记录。

</details>

<details>
<summary><strong>转账为什么不显示归属、发起者和记录者？</strong></summary>

转账表示自己的两个实际账户之间移动资金，不改变成员归属，也不算收入或支出，因此只需要选择转出账户和转入账户。

</details>

<details>
<summary><strong>换手机或卸载前需要做什么？</strong></summary>

请先从设置导出 ZIP 或 JSON 完整备份，并把文件保存到其他设备或云盘。应用内快照无法在卸载后保留。

</details>

<details>
<summary><strong>旧版数据可以继续使用吗？</strong></summary>

可以。应用会升级已有数据库；也可以从旧版的一笔 ZIP 或 JSON 归档恢复。升级或恢复前仍建议额外保留一份原始备份。

</details>
