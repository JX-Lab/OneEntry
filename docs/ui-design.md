# 一笔界面设计

## 设计意图

打开应用先看清最近发生的账，再快速记下下一笔。账户表示钱实际存放的位置；成员荷包表示资金归属。两套信息在页面上分别呈现，金额和时间优先于装饰。

## 视觉规则

- 品牌动作与月度汇总使用翡翠绿；收入使用蓝色，支出使用红色。统计的两条折线都是实线，图例和点选后的日期金额补充文字说明。
- 浅色背景为微绿灰 `#F5F8F5`，白色承载账目和表单；深色背景为 `#111A17`，表面为 `#1C2623`。强调色仍跟随用户选择的主题色。
- 页面主体以 12–18 像素的间距分组；摘要卡圆角 18，账目和列表行圆角 12，按钮和输入圆角 14。普通条目靠留白和浅色分隔建立秩序，避免叠加重阴影。
- 金额比分类和备注更醒目；相邻账目的金额使用等宽数字。辅助文字使用主题的次级文字色，确保浅色与深色界面都能阅读。
- 输入框失焦以及键盘收起时不显示描边；聚焦由光标、底色和标签颜色提示。选择器保留明确的选中状态与可点击面积。

## 页面层级

| 页面 | 首要信息 | 主动作 | 次要内容 |
| --- | --- | --- | --- |
| 首页 | 月度收支与按日期排列的账目 | 记一笔 | 成员、账户、统计入口；搜索和多选 |
| 记一笔 | 类型与金额 | 保存账目 | 分类、付款／归属、记录、账户、时间、备注和周期设置 |
| 账户 | 账户净额与实际账户列表 | 新增账户 | 账户详情、归档和余额调整 |
| 成员 | 荷包与往来入口、成员列表 | 新增成员 | 成员详情、归档和结算 |
| 预算 | 当月剩余额度与使用进度 | 编辑预算 | 分类、可选成员预算和预算外支出 |
| 统计 | 时段收支趋势及精确金额 | 切换时段与分类 | 标签和成员构成、明细下钻 |
| 设置 | 按用途分组的偏好 | 修改对应设置 | 提醒、外观、数据与备份 |

## 交互与适配

- 高频主动作保留固定位置。点按、分类选择、展开和底部面板使用短过渡，内容状态立即更新，不增加开屏等待。
- 成员与账户选择支持搜索；余额不足时提示剩余金额和可用来源。输入错误时保留已填内容，原位给出可恢复的说明。
- 390×844 为主视口；360×800 和 200% 字号时，日期小计、账户及成员条目改为上下排列，保持金额、名称和操作可读。页面保留纵向滚动，不缩小放大后的文字以强塞进一行。
- 用户开启夜间主题或色觉辅助模式时，金额仍带正负号及文字含义；颜色不承担唯一信息。

原有记账、转账、荷包演算、预算、统计、搜索、多选、提醒、备份和导入逻辑均沿用现有实现。
